# Rally Landing Page

Build a single-page, high-converting landing page for Rally — an AI agency that deploys AI agents for orthodontic practices. The single goal of this page is to get ortho practice owners to book a discovery call.

Reference site: https://flexfollio.framer.website/ — I want you to closely match this site's layout, design patterns, spacing, and feel, but with Rally's branding and content. Match the reference's design language as closely as possible. Visit the URL to see the full site.

The section order on the reference is: Nav → Hero (light bg + floating dashboard screenshot) → Trust bar (logos) → About Company (large text + floating tag pills + stats) → Benefits (3+2 card grid) → Features/AI-driven (alternating full-width cards) → Features/Smarter tools (bento grid) → How it works (3 steps with dashed lines) → Testimonials (carousel) → Pricing (3 tiers) → FAQ (two-column) → Final CTA (gradient image card) → Footer. Follow this same order with Rally's content.

Brand

Name: Rally

Primary color (burgundy): #6B2332

Ink (dark text): #1A1A17

Bone (warm background): #F5F1E8

Warm grey (muted text): #8A8578

White: #FFFFFF

Accent tint: Use rgba(107,35,50,0.08) for light burgundy tinted backgrounds on icons and badges

Fonts: Use a clean sans-serif (Inter or similar) for body text. Use a serif (Playfair Display or similar) for headlines — gives it a premium, warm editorial feel.

Wherever the reference site uses orange, use burgundy #6B2332 instead. Wherever it uses light orange tints, use light burgundy tints.

Design patterns to match from the reference

Section label pills

Every section has a small rounded pill/badge at the top with an icon and label text (e.g., "How it works", "Features", "Pricing", "FAQs"). These have a very subtle background, thin border, small icon on the left, and muted text. Replicate this exact pattern for every section using burgundy tints instead of orange tints.

Hero

The hero is NOT a full gradient fill. It's a clean, light background (white or very subtle warm tint) — matching the reference's Flexfolio hero exactly. The layout is:

A small pill badge at top center (e.g., a dot icon + "AI-Powered" label)

Large centered serif headline (dark text, not white)

Subtitle text in muted grey below

A filled burgundy CTA button (not white — burgundy background, white text)

Below the button: a social proof row with overlapping avatar circles + review count + star rating

Below all of that: a large floating product screenshot/mockup showing a dashboard or chat interface — this is the visual anchor of the hero, just like in the reference. Use a mock dashboard showing Rally's agent in action (conversation stats, lead pipeline, show-up rate metrics). The screenshot should have a subtle shadow and slightly overlap the next section.

Very subtle warm gradient tints in the background (not a bold gradient — just soft, barely-there warmth) Save the bold burgundy gradient for the final CTA section at the bottom instead.

How it works section

Three steps in a row, each with a circular icon above. Connect the circles with dashed curved lines (like the reference) — this is a key visual detail. Each step has a bold title and muted description below.

Features — bento grid layout

Match the reference's features layout: a large card (2/3 width) next to a smaller card (1/3 width) on the first row, with more cards below. Cards have a light background, subtle border, a visual/illustration area at the top, and title + description below. Use the bento/asymmetric grid, not a uniform grid.

Testimonials

Three testimonial cards in a row with navigation arrows (left/right) in the top right. Each card has: avatar circle, name (bold), title/company (muted), star rating row (5 stars in burgundy/orange), and a quote in quotation marks. Match the reference's card style with subtle borders.

FAQ — two column

Dark ink (#1A1A17) background. Left: Rally logo + tagline + social icons. Middle columns: "Company" links and "Product" links. Right: "Newsletter" with email input and subscribe button (burgundy). Copyright bar at the bottom.
